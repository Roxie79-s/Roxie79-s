## 🚀 Featured Projects

### 🌌 NebulaX: AI-Powered Penetration Testing Platform
A MERN-based pentest platform that brings reconnaissance, vulnerability assessment and reporting into one workflow.
- Integrates **OSINT, Nmap and OWASP ZAP** with a React UI, Node/Express REST APIs and MongoDB storage
- Threat-intel enrichment via **VirusTotal, AbuseIPDB and NIST NVD**
- Generates structured **PDF reports with CVSS-based prioritization**

`React` `Node.js` `Express` `MongoDB` `Nmap` `OWASP ZAP`

### 🧪 WinLive Forensic Suite (WLFS)
A Python/PySide6 GUI tool that automates live forensic acquisition, so investigators don't need manual command-line steps.
- Collects **memory, registry, browser and system artifacts**
- **WinPmem** for RAM acquisition, **Volatility**-compatible output
- Cut evidence preparation time by roughly **70%** during my internship

`Python` `PySide6` `WinPmem` `Volatility`
